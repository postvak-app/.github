**Postvak** is a fast IMAP mail client with rules that keep your mailbox clean. It syncs in the background, sorts mail with rules you write in `rules.toml`, and gives you a keyboard-driven mail window, a full command line and an MCP server for agents. It runs on macOS and Linux.

- [Postvak](https://github.com/postvak-app/postvak): the app
- [Documentation](https://postvak.pataar.nl/): install, accounts, rules, agent guide and CLI reference
